# Demo links

Replace `YOUR-USERNAME` with your GitHub username once Pages is on
(Settings → Pages → Deploy from a branch → `main`, `/ (root)`).
Each link opens paused; press Play or the space bar.

| What | Link |
|---|---|
| Gladiolus, seed G3, Now | `https://YOUR-USERNAME.github.io/petals-time/#seed=G3&family=2&age=7301&v=0.6.0` |
| Same organism at −20 years | `https://YOUR-USERNAME.github.io/petals-time/#seed=G3&family=2&age=1&v=0.6.0` |
| Same organism at +20 years | `https://YOUR-USERNAME.github.io/petals-time/#seed=G3&family=2&age=14601&v=0.6.0` |

| First renderer, 0.4.0 | `https://YOUR-USERNAME.github.io/petals-time/#seed=K1&age=7301&v=0.4.0` |

Link parameters: `seed` (or `birth` as `YYYY-MM-DDTHH:MM`), `family` (−1 mixed, 0 poppy,
1 bracts, 2 gladiolus, 3 ink tulip, 4 fibre x-ray, 5 spectral iris), `age` (1–14601, Now = 7301),
`v` (renderer version).
